# Hunter's portfolio

The React + TypeScript + Vite app is in [`hunter-portfolio-starter/`](hunter-portfolio-starter/). Open that folder in VS Code and run build/development commands there.

Production is hosted by the existing Vercel project **huntrr-portfolio**, at https://huntrr-portfolio.vercel.app. Set Vercel's **Root Directory** to `hunter-portfolio-starter`, **Build Command** to `npm run build`, and **Output Directory** to `dist`.

See the [deployment guide](hunter-portfolio-starter/DEPLOYMENT.md) for all dashboard settings and the GitHub → Vercel workflow. The existing production branch is `master`.
